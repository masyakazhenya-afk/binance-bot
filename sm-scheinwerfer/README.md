# SM Scheinwerfer – Website
Statische Seite (HTML/CSS/JS), ohne Build. Einfach `sm-scheinwerfer/` hochladen oder lokal `python3 -m http.server`.
Seiten: index (Leistungen, Vorher/Nachher, Ablauf, Vorteile), ueber-uns, einsatzgebiet, termin (Formular -> WhatsApp).
Fotos: `assets/` (mercedes-/van-before|after.jpg ersetzen oder neue Slider in index.html ergänzen).
